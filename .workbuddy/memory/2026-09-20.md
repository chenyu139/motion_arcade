# 2026-09-20 工作日志

## Active Arcade 竞品分析与战略判断
- 研究对象：Active Arcade（NEX Team，前苹果工程师团队，HomeCourt 起家），摄像头体感游戏 App，纯端侧全身姿态识别，12 个小游戏，免费无广告。
- 关键事实：NEX 创始人复盘称手机形态"留存浅、错平台"，连电视后留存 +10x，已转型 Nex Playground（AI 摄像头+主机硬件，2025 售 63.5 万台）。纯手机体感游戏赛道原创团队已放弃。
- 能力对照（我们 vs NEX）：端侧 17 关键点姿态(GuanPose/RTMPose-S)、iOS/Android 摄像头管线、实时渲染(NBA 实时流)、运动专项模型 均"已有"；AR 叠加/大屏投屏/精彩集锦"部分"；游戏玩法设计/美术音乐音效/多人联机"缺口"。
- 结论：核心硬科技已具备，不建议复刻独立 App；应作为技术验证+能力复用，载体走"嵌入川观客户端+大屏"，差异化用运动专项姿态模型。待用户确认是否拉 MVP 技术方案。
