# 2026-09-30 工作日志

## Android 原生迁移（Kotlin + CameraX + MediaPipe），首轮 5 款游戏

### 选型争议（用户中途质疑，值得记住）
用户问："项目是 Python/pygame，为什么不直接用 Chaquopy 或 p4a 让 Python 跑在 Android 上？"
—— 这个质疑是对的，我一开始没先论证就默认重写，属于疏漏。查证后结论：

- **Chaquopy**：只提供嵌入式 CPython + numpy/opencv 等 C 扩展，**没有 SDL 窗口系统**，
  pygame 拿不到 surface，根本无法渲染 → 排除。且是商业 SDK（免费版有通知+时限）。
- **p4a/Buildozer + pygame**：能跑（sdl2 bootstrap + pygame-ce recipe），但
  ① recipe 自述 *"freetype, portmidi, libjpeg not part of the build"* ——
     **freetype 缺失 = 中文渲染废掉**，本项目 HUD/菜单/提示条全靠中文，致命；
  ② 摄像头：`cv2.VideoCapture` 在 Android 拿不到画面，必须 pyjnius 调 CameraX；
  ③ ML：MediaPipe pip 包是桌面编译版，Android 跑不了。
  → 即"直接跑 Python"省掉的只有游戏逻辑，而摄像头+ML 两块在任何方案里都躲不掉原生。
- **定为原生 Kotlin**（用户拍板"只移植部分游戏到原生"）。

### 已落地（提交 f792ac1，36 文件 4485 行）
- 技术栈：Kotlin 2.2.21 / AGP 8.13.2 / Gradle 8.13 / compileSdk **36**（CameraX 1.6.2 要求 ≥36）
  / CameraX 1.6.2 / **MediaPipe Tasks Vision 1.0.0（正式版）** / Canvas 硬件加速。
- 分层：
  - `vision/` CameraManager(CameraX) → LandmarkerHub(Pose33/Hand21/Face468, GPU+CPU兜底) →
    VisionPipeline(校准/滤波/边沿) → GameInput

    BackgroundManager(cover 适配+渐变兜底)
  - `game/` BaseGame(粒子池/屏震/闪白) / GameRegistry / games/ ×5 / GameSurfaceView(独立渲染线程 60fps)
  - `ui/` Menu 大厅（触摸 + 头部双通道选择）
- 游戏 5 款：mario / panda_roll / ski（头控）+ slice / hoop（手控）。
  物理常量逐项对齐 Python 端（GRAVITY 2600 / JUMP -920 / MAX_RUN 430 / COYOTE 0.10 等）。
- 手感四要素：中性位校准、尺度归一（÷眼距肩宽）、One Euro 自适应滤波、边沿量 pending 不丢帧。

### 踩过的坑（重要）
1. **Kotlin 插件 "not found"**：真因不是版本错，是本机 Java 访问 Maven Central 被掐 TLS。
   解法：repositories 加阿里云镜像（详见用户级记忆）。别去改版本号。
2. **compileSdk 一路抬高**：34 → 35（media3/featurecombinationquery 要求）→ 36（camera-core 1.6.2 要求）。
   顺带**移除了 camera-view**（画面是 Canvas 自绘，不需要 PreviewView，还能减包体）。
3. **apply(plugin=) 会丢失 Kotlin DSL 类型安全访问器**（57 个 unresolved）→ 改回 plugins DSL。
4. **gradlew 不能生成**：`gradle wrapper` 任务要联网校验发行版 URL（Java 下必失败）。
   改成 shell 薄封装 `android/gradlew`：优先 `~/gradle-dist/gradle-8.13`，缺失用 curl 下载。
5. MediaPipe API 实际返回 `NormalizedLandmark`（不是 `Landmark`）；`Delegate` 在
   `com.google.mediapipe.tasks.core.Delegate`。

### 工程约定
- **运行期资产不入库**：`android/scripts/prepare_assets.sh` 下载 3 个 .task 模型（17MB）
  + 从项目 `assets/` 复制并降采样精灵(→512)/背景(→1920/1280)。避免仓库胖 30MB+，

- APK ≈ 54MB。发布时可去 x86_64 ABI（省约 14MB）或改 App Bundle。

### 重要 bug：返回大厅必现的 MediaPipe 原生崩溃（首日移植埋的雷）
- 现象：游戏返回大厅时 SIGSEGV（fault addr 0x10），tombstone 落在 `PoseLandmarker.detectAsync`。
- 根因：`retune()/stop()` 在**主线程** close landmarker，相机线程同一时刻在 `detectAsync` —— use-after-close。
- 修复：LandmarkerHub 加 `mpLock`（ReentrantLock），ensure/release/detect 全部串行化；粒度到单次提交/close，主线程阻塞几毫秒可忽略。与"rebuild 必须在推理线程"同源：**MediaPipe 实例的一切交互必须串行**。
- 验证：两轮 游戏→大厅→游戏 连续切换，crash buffer 零记录。

## 续3：交互重构 + 摄像头策略 + 局限应对（三个方向完整落地）

### 背景
用户问"体感交互怎么设计才自然/前后置摄像头怎么选/手机摄像头相比游戏机的局限"，
我给了详细分析（动词要具身、疲劳预算、镜像演示、文化动作即动词；前置=手机当屏、
后置=手机当主机配大屏；无深度/热节流/卷帘快门/AE泵四大局限）。用户拍板三个方向
"依次做、完整做完、不做原型"。

### 方向1 交互重构
- **手势词表进 GameInput**：nod(点头边沿)/duck(低头状态)/swing(横扫边沿)/
  handVx·Vy/handDipL·R(左右拳下砸速度)/handZ(推近 pseudo-depth, 掌宽比个人基线)/
  handTilt(手腕倾斜)。jump 语义从"持续仰头"改为"点头或张嘴的边沿"。
- **校准无感化**：删掉"站好别动 0.4s"阻塞式校准 → 重捕获瞬时对齐 + 连续慢速跟随
  （只在 |axis|<0.35 时跟随，防止偏移姿态被吸回中心）。
- **8 款现有游戏动词重排**：Mario/Ski/PandaRoll/Football 触发=点头；Hotpot=低头
  （头就是筷子，保持低头=连续捞）；Tennis 升级为头+手分工（头跑位、手横扫=挥拍）。
- **两款文化动词新游戏**：
  - mask 川剧变脸：手掌扫过脸=变脸，匹配目标脸谱，60 秒计分（连击/锣声/戏台
    幕布灯笼全程序绘制，mask 五张精灵进白名单）。
  - drum 蜀韵鼓点：握拳下砸=击鼓，40 音符川剧锣鼓谱面，短语头=锣点。
- **发现并修复既有 bug**：HUD 写"已暂停"但时间驱动游戏在通道丢失时照常扣血/计时
  （模拟器网球被打 0:5 的真凶）→ 场景层加 ready 门（所需通道全在线才推进游戏）。

### 方向2 摄像头策略
- CameraManager 支持 lens 切换（setLens 即时重绑定）；启动时检测外接显示
  （DisplayManager）自动切后置——手机当主机形态，也更接近 A311D2 终态。
- 成像稳定性对标游戏机摄像头：AWB 第一帧锁；后置 AF off + 对焦无穷远；
  AE 启动 2.5s 收敛后经 Camera2CameraControl 锁定（API 是
  setCaptureRequestOptions(CaptureRequestOptions)，不是单键方法，踩了一下）。
- 预览缩略图前置按镜子镜像；手 x/手腕倾斜在回调源头随镜头镜像，下游统一屏幕方向。

### 方向3 局限应对
- perfTier（0/1/2）：热状态（MODERATE/SEVERE，API29/31+）+ 推理吞吐（结果回包率
  <60%/35%，2s 窗口）→ 分析跳帧，渲染同步降 30fps（GameSurfaceView 读 perfTier）。
- 音频延迟：Sfx.attach 读系统 "audio_output_latency"；drum 开局 4 拍自动校准，
  结果存 GamePrefs（"drum_offset_ms"），判定窗以"听到的时间"为准。
- 光线提示：相机线程每 30 帧采 16×12 网格亮度，<40 提示"光线偏暗"。

### 验证
编译零告警；模拟器：大厅 10 款 5×2 网格（Menu 自适应）、变脸/鼓点画面完整、
暂停门生效（鼓点 8 秒无手 5 心不减）、零崩溃。APK 35.2MB（+1.6MB=5 张脸谱）。
